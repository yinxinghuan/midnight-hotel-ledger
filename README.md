# THE MIDNIGHT HOTEL LEDGER

一款生成式影像驱动的荒诞酒店互动短剧。玩家在 02:17 接管 307 号房的异常投诉，为“浴缸传来海浪声”选择三种处理代码，并收集三个独立的电影式结局。

```bash
npm install
npm run dev -- --host 127.0.0.1 --port 5173
```

项目为原创实现；静帧、结局画面和视频通过 Aigram 平台生成接口制作，并由酒红皮革与黄铜夜班终端 UI 串联。视频不可用时会自动回退到对应静帧，玩法不会中断。
