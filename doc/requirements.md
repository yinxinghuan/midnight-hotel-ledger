# 《午夜酒店值班簿》需求文档

## 1. Overview

一款 45–60 秒完成一案的竖屏生成式互动黑色喜剧：午夜酒店经理发现 307 号房浴缸通往海底，玩家从夜班终端选择处置方式，观看对应的真人超现实短片并归档三个结局。

## 2. Visual Design

- 基准视口 390 × 844，短屏覆盖 320 × 568。
- UI 是一台属于老牌精品酒店的午夜值班终端：酒红皮革、氧化黄铜、暖黑玻璃和米色打字纸。
- 视频画面为 3:4 真人电影中景，固定人物是欧美年轻女性夜班经理 Mara、年长男性住客和同一间古典酒店浴室。
- 生成影像内部无文字、Logo 或 UI；操作、字幕和结果档案由 DOM 叠加。

## 3. Game Mechanics

- 场景数：1；选择数：3；独立生成视频：3；可归档结局：3。
- 状态：`cover → incident → footage → report → incident`。
- 选择前使用三段视频共同的精确首帧；视频 `canplay` 后 180 ms 交叉淡入。
- 五拍时间点：0 ms 受理、650 ms 预兆、2200 ms 异常升级、4100 ms 稳定、5200 ms 归档。
- 三条处置：
  1. **塞住排水口**：Mara 按下黄铜塞，浴缸突然喷出小型海浪和热带鱼。
  2. **呼叫维修**：Mara 举起服务铃，一个无人古董潜水头盔连着黄铜工具箱从浴缸浮起，作为海底自动维修包。
  3. **升级为海景套房**：Mara 展开房卡，一条礼貌的巨大章鱼触手端着银色客房餐盘升出水面。
- 视频目标时长 4.8–5.5 秒，统一在 5200 ms 进入结果；加载失败仍进入对应尾帧。
- 归档键为 `bath:<endingId>`，写入 `midnight_hotel_ledger_reports_v1`；3/3 后显示“307号案卷封存”。

## 4. Controls

- Pointer / Touch：开机、三个处置、声音和“重新调阅”使用 `onPointerDown`。
- Keyboard：`Enter` 开机或重阅，`1 / 2 / 3` 选择，`M` 切换声音。
- 触控目标至少 44 × 44 CSS px；录像播放时不接受重复选择。
- 全局禁止 iOS 长按 callout、图片拖拽和非编辑文本选择。

## 5. Win / Lose Conditions

- 无传统胜负；看完一个处置视频即完成一次案件归档。
- 报告页显示案件标题、事故摘要、`新档案 / 已调阅`、`x / 3` 进度和重新调阅按钮。
- 三份档案全部收集后显示“307号案卷封存”，玩家仍可继续播放任一录像。

## 6. Sound Effects

- 终端开机：90 → 240 Hz 正弦上滑，360 ms，音量 0.035。
- 处置确认：380 Hz 三角波，70 ms，音量 0.03。
- 水压预警：120 / 105 Hz 两次正弦脉冲，间隔 160 ms，音量 0.035。
- 海浪：80 → 46 Hz 噪声与低频包络，420 ms，音量 0.055。
- 维修铃：620 / 930 Hz 正弦双音，180 ms，音量 0.035。
- 房卡批准：310 / 465 / 620 Hz 三音和弦，300 ms，音量 0.04。
- 归档盖章：72 Hz 方波撞击，160 ms；静音或 Web Audio 失败不阻塞视频。
