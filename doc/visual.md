# 《午夜酒店值班簿》视觉文档

## 1. 视觉论点

“一家不承认超自然事件存在的老牌酒店，仍把每次异常认真当作服务流程。”玩家记住的画面应是八只紫色触手同时操作黄铜前台，而值班经理终于打卡下班，身后海水仍从 307 号房流进大厅。

## 2. 构图与镜头

- 390 × 844 竖屏；顶部 72–82 px 为酒店铭牌、三场进度和声音，中部 350–500 px 为监控 / 录像窗，底部为一句事故与三个处置。
- 第一场在同一间古典酒店浴室；第二场移动到同酒店前台登记台；第三场仍在同一前台并扩大到八个服务铃。Mara、年长住客、紫色章鱼、酒红制服与黄铜材质必须连续。
- 播放时处置单退场，只保留细窄案件编号、时间码和字幕；结果像纸质报告从终端打印槽滑出。
- 平台内构图不为外部访客栏预留空间。

## 3. 色彩系统

- `wine #4B1724`：皮革外壳和主品牌色。
- `brass #C5A05A`：边框、编号和高价值状态。
- `night #111417`：玻璃、暗部和外部背景。
- `paper #E8DEC9`：档案纸与正文承载。
- `sea #2B7185`：异常水光、选择状态和录像反馈。
- `alarm #B7463A`：错误、警戒和重新调阅。

## 4. 字体系统

- 酒店名：Cormorant Garamond / Songti SC，32–42 px，600 weight。
- 案件与按钮：Arial Narrow / PingFang SC，13–17 px，700–900 weight。
- 打字报告：Courier New / Menlo / PingFang SC，14–17 px，行高 1.45。
- 数字使用等宽字体，避免时间码和案件号跳动。

## 5. 形状、材质与光

- 外壳使用直角与 2–3 px 黄铜镶边；皮革只有轻微压纹，不使用大圆角和玻璃拟态。
- 视频光线为月夜钨丝灯与冷蓝海水反光，人物肤色自然，不使用赛博霓虹。
- 选择键像黄铜电梯按钮与档案标签结合，按下时机械下沉 3 px。
- 报告纸带有打字机墨迹、细折痕和一次红色归档章。

## 6. 素材规则

- 所有首尾帧通过 Aigram 平台 transit 生图接口制作，视频通过正式首尾帧视频接口制作。
- 选择前图片、三条视频第一帧、视频 `poster` 和失败回退使用同一精确首帧。
- 固定人物 Mara：欧美年轻女性、深棕短波浪发、酒红酒店制服、黄铜名牌；住客：年长白人男性、灰色睡袍。
- 生成画面内部禁止文字、Logo、水印、中文、终端 UI 和字幕。

## 7. UI 与图标

- 开机按钮是长方形黄铜钥匙槽；三个处置是编号为 `1 / 2 / 3` 的短句，取消需要解码的 `A-17 / B-04 / C-88` 档案代码。
- 声音、重播和返回使用统一 24 px、2 px 方头自绘 SVG，颜色来自黄铜与纸色。
- 加载态保留首帧，显示窄扫描线和“录像装片中”；错误态保留首帧并允许流程继续。
- 禁止 Emoji、流媒体播放键、紫色 AI 渐变、发光药丸按钮和通用 SaaS 面板。

## 8. 动效与特效

- 开机 420 ms：黄铜刻度依次亮起，玻璃由黑转为浴室首帧。
- 选择 100 ms 下沉；首帧保持；视频可播后 180 ms 交叉淡入。
- 播放只叠加细微扫描线、时间码与五拍字幕，不遮挡人物和浴缸。
- 结果纸 280 ms 从下方打印，盖章在 120 ms 接触并回弹；减少动态效果时直接切换静态尾帧。

## 9. 参考转译

- 老酒店前台转译为皮革、黄铜、房卡和服务铃，不复制具体酒店品牌。
- 1970年代监控终端转译为克制时间码和扫描线，不做满屏 VHS 故障滤镜。
- 黑色喜剧转译为人物一本正经地处理荒谬现象，避免恐怖跳吓和血腥。

## 10. 禁止模式

- 禁止沿用手绘游戏或《千万别选正常答案》的小报、剪纸、红黑标题结构。
- 禁止三个分支只替换字幕；每条必须拥有独立视频和尾帧。
- 禁止选择前后更换演员、浴室、机位或光线；禁止先切黑再播放。
- 禁止生成画面出现乱码、中文、酒店 Logo 或 UI。

## 11. 垂直切片验收

- 封面、三场案件页、每场共享首帧、九条录像、九个报告和最终完成状态完整。
- 遮住字幕仍能区分海浪与鱼、无人维修箱、章鱼入住、八手签名和章鱼接管前台等九个结果。
- 每场问题页图片、演出层图片和该场三个视频 poster 的像素来源完全一致。
- 390 × 844 平台内完整展示；320 × 568 等短屏按宽度铺满并允许纵向滚动，不以高度压缩整张画面，关键脸部保持在可见主镜头内，触控目标至少 44 px。
- 视频失败、静音、英文和减少动态效果均能完成归档；外部访客栏不反向改变平台内构图。
